# Changelog

All notable changes to this project will be documented in this file.

## [v1.0.0] - Launch Release

### Added
- **Core Architecture:** Custom Node.js Static Site Generator (`build.js`) configured for blazing-fast localized builds.
- **UI Design System:** Custom Glassmorphism UI, Dark/Light Mode, responsive grid layout.
- **70 Fully Functional Tools** across 10 Categories:
  - **PDF Tools (10):** Merge, Split, Optimize, Convert, Watermark, etc.
  - **Image Tools (10):** Compress, Resize, Crop, Convert, Watermark, ICO Generator, etc.
  - **Text Tools (10):** Word Counter, Case Converter, Line Duplication Remover, etc.
  - **Student Tools (10):** Calculators for Attendance, Grades, BMI, Age, etc.
  - **Developer Tools (20):** Formatters (JSON, HTML, CSS, JS, SQL, XML), Minifiers, Hash Generators, Base64, UUID, Regex, JWT, etc.
  - **Calculator Tools (10):** Finance & Math calculators (EMI, SIP, Loan, Compound Interest, Tax, etc.)
- **SEO Optimization:** Schema.org JSON-LD generation for SoftwareApplication, BreadcrumbList, and FAQPage. Dynamic canonical links and meta tags.
- **Progressive Web App (PWA):** Fully offline-capable manifest and service worker config.
- **Monetization & Analytics:** Configured placeholders for AdSense, Google Analytics, and Microsoft Clarity.
- **Deployment Pipelines:** Configured for Vercel, Netlify, Cloudflare, and GitHub Pages.

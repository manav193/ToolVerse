# 🚀 ToolVerse

ToolVerse is a modern collection of **70+ free online tools** built using **HTML, CSS, Vanilla JavaScript, and Node.js**.

The project focuses on speed, privacy, SEO, and accessibility while keeping everything lightweight and completely client-side whenever possible.

- 📄 PDF Tools

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/ToolVerse.git
```

Install dependencies

```bash
npm install
```

Build the project

```bash
npm run build
```

Run locally

```bash
npm run serve
```
